# Pocketa Blue Ledger

三頁式個人記帳 PWA，以深藍至白色漸層與黑色文字呈現。繁體中文、新臺幣、臺灣時區。

## 功能

- **當月總覽**：當月份存款（當月結餘）、總收入、總支出、較上月差額、最近收支、未到期固定項目及支出分布。
- **收支記帳**：一般收入／支出新增、修改、刪除；可收合分類 NAV 顯示整月分類小計；月份、類型、分類及文字篩選。
- **固定收支**：每月規則、開始／結束日期、暫停／恢復、月底調整、開啟時補建、防重複及刪除紀錄防補建。
- **年度結餘**：可收合的真正 HTML table。每個年度框左側年份、右側年度結餘，展開 12 個月，表格最底部年度加總。
- 完整 JSON 備份／還原、CSV 匯出、分類新增／改名／封存、獨立範例帳本。
- 響應式畫面、底部分頁 Bar、Web App manifest、離線快取。

## 本機啟動

需要 Node.js 20 或更新版，不需要安裝 npm 套件。

```sh
npm start
```

開啟 http://127.0.0.1:4173 。也可使用任何靜態網頁伺服器提供 `dist/`；不要直接以 file:// 開啟，模組與離線功能需要 HTTP(S)。

## 檢查

```sh
npm test
```

核心測試包含金額精度、閏年與月底、跨年、定期補建、防重複、刪除防補建、暫停恢復、修改保留歷史、預估排除、備份驗證及 CSV 格式。

## 資料保存與隱私

資料僅儲存在目前網站來源下的 localStorage；沒有銀行串接、雲端帳本或帳號同步，也不會把使用者的帳目上傳到 GitHub。原始碼中的範例資料是虛構的。不同網址／瀏覽器／裝置的帳本彼此獨立，移轉時請使用完整 JSON 備份。

localStorage 有容量上限，建議定期備份。資料讀取失敗時會停止寫入，保留原始內容供下載救援。還原會取代目前帳本，須在畫面確認。CSV 僅供閱覽，不包含固定規則，不能用於完整還原。備份含個人財務資料，請自行妥善保管。

「自動扣款」僅代表依規則自動記帳，不會執行銀行付款或驗證入扣款。關閉 APP 期間不保證背景執行，下次開啟或回到前景時補建。暫停期間不補建。年度統計不含未到期預估收支。

## 安裝與部署

以 HTTPS 提供 `dist/` 靜態檔案。瀏覽器支援時可使用「加入主畫面」；首次完整載入後可離線操作。iOS 與 Android 的安裝提示及離線能力依瀏覽器而異，尚未進行實體手機驗證。

`dist/` 支援網站根路徑與 GitHub Pages 的儲存庫子路徑。GitHub Pages 可部署 `dist/`，不需要建置步驟。發布用靜態檔案位於 `gh-pages` 分支根目錄，包含 `.nojekyll`。在 GitHub Settings → Pages 選擇 Deploy from a branch、`gh-pages`、`/(root)`，儲存後由 GitHub 建置。若畫面要求升級或公開儲存庫，先由擁有者決定；不能假定 Pages 已啟用。

後續修改時需同時更新 `main` 的 `dist/` 與 `gh-pages` 根目錄，兩者內容一致後再確認 Pages 建置結果。未設定 GitHub Actions 自動同步。

網站網址切換會形成不同的本機帳本：若舊 Sites 網址已有資料，先下載 JSON 備份，再到 GitHub Pages 還原，資料不會自動移轉。

RWD 已檢查 280–2560 CSS 像素的 10 組尺寸與三頁、表單操作；保留原配色及版面結構。詳見 `QA.md`。

Sites 專用的 `.openai/hosting.json` 保存此專案的託管識別，不含帳本或登入憑證。

## 專案結構

- `dist/index.html`、`style.css`：畫面與樣式。
- `dist/app.js`：畫面互動、持久化、匯入匯出。
- `dist/core.js`：日期、金額、定期規則、統計與資料驗證。
- `dist/sw.js`、`manifest.webmanifest`：離線快取與安裝資訊。
- `tests/core.test.mjs`：核心自動測試。
- `PLAN.md`：確認後的需求與範圍。
- `QA.md`：本次檢查結果。


## Pocketa v1.1.0：資料與設定
第四頁集中 JSON 備份／還原、CSV、分類管理、範例帳本及版本更新。更新按鈕會查詢 version.json，確認新版首頁已發布後自動重新開啟；不清除 localStorage。網路或發布異常會顯示可重試提示。

後續發布必須同步遞增 dist/update.js 的 RELEASE.build、dist/version.json 的 build、首頁 pocketa-build、資源查詢版本及 sw.js 的快取版本，並同步 version/date。請將所有 dist 檔案（含 update.js、version.json）一起發布到 gh-pages，避免只更新版本描述。
